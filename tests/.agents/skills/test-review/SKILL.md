# Test Review Skill (测试方案评审)

本技能指导 AI 智能体对已生成的测试方案与代码进行严格的“反思与质检”。

## 审查重点 (Checklist)

1. **真实断言有效性**：用例内部是否存在仅 `assert True` 或仅判断响应码的“假通过”代码？
2. **证据链完备性**：高风险 P0 场景是否通过 `attach_evidence` 上报了 DB 快照或 Trace？
3. **未覆盖盲区**：比对需求条款，是否存在未被任何测试覆盖的孤岛章节？
