# Test Validate Skill (因果对账与门禁)

本技能指导 AI 智能体对比 Git 变更分支与测试覆盖矩阵。

## 对账流程

1. **拉取 Git Diff**：分析提测分支的改动行与受影响函数。
2. **拓扑匹配**：利用图谱与 AST 扫描，计算每个改动函数是否有对应用例覆盖。
3. **输出五问门禁答卷**：
   - Q1: 本次改动的核心业务风险是什么？
   - Q2: 核心业务逻辑是否有真实执行证据？
   - Q3: 遗留的未覆盖代码盲区有哪些？
   - Q4: 架构依赖与上下游爆炸半径如何？
   - Q5: 是否达到准出标准？
