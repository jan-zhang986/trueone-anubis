# Test Design Skill (需求与风险梳理)

本技能指导 AI 智能体与测试人员在进入编码前，对业务需求进行深度拆解并完成 FMEA 风险分析。

## 工作规程 (SOP)

1. **阅读需求与边界**：精读需求条款，识别业务核心路径与异常分支。
2. **状态机与资损分析**：梳理状态迁移图（如 APPLIED -> PROCESSING -> SUCCESS），找出非法跳转分支。
3. **输出 FMEA 风险卡片**：
   - 风险项名称 (如：并发幂等拦截失效)
   - 风险定级 (`P0` / `P1` / `P2`)
   - 影响范围 (表名、服务接口、资金流)
   - 规避验证策略
